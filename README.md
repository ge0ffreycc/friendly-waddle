# 桌面每日计划 · DeskTop Plan App

一款适配 Windows 11 风格的轻量级桌面端每日计划应用，专注于「不打扰、随手记」的使用体验。

---

## ✨ 功能特性

### 📋 每日计划管理
- **新增任务**：在顶部输入框回车即可快速添加今日计划
- **标记完成**：点击左侧复选框切换任务完成状态
- **双击编辑**：双击任务文本直接修改内容
- **删除任务**：点击右侧删除按钮移除任务
- **日期切换**：顶部日期栏支持查看/编辑任意一天的计划（左右箭头或点击日期跳转）

### 🧳 遗留任务自动迁移
- 前一天（或更早）未完成的任务，会在启动应用时自动迁移到今日列表
- 迁移的任务带有**来源日期标签**（如「昨天 · 遗留」「8月31日 · 遗留」），一眼区分新任务和老任务
- 已迁移的任务不会重复迁移，完成后自动归档

### 🏁 桌面边缘缩进（核心特性）
靠近桌面任意边缘（左 / 右 / 上）时，窗口会自动缩进至屏幕外，仅保留一条 12px 的可见边条，极大节省桌面空间：

| 状态 | 说明 |
|---|---|
| **缩进中** | 窗口只露出一条边，鼠标移动到可见条上会自动展开 |
| **展开中** | 窗口完整显示，鼠标移出窗口 700ms 后且窗口贴边时自动缩回 |
| **自由拖动** | 支持任意拖动窗口，拖离边缘后不再自动缩进，可作为普通浮窗使用 |

### 📌 其它实用特性
- **窗口置顶**：默认始终保持在所有窗口最上层，右上角按钮可切换置顶状态
- **无框透明设计**：无边框 + 毛玻璃效果，完美融入 Win11 桌面
- **本地数据存储**：所有数据保存在本地 `appdata/` 目录，无需联网、无需登录
- **GPU 兼容模式**：内置 `--disable-gpu` 参数，兼容权限受限/沙箱环境

## 🚀 快速开始

### 环境要求
- Windows 10 / 11
- Node.js ≥ 16

### 安装与启动

```bash
# 1. 安装依赖（首次使用）
npm install

# 2. 启动应用（两种方式二选一）
npm start
#  或者直接双击： 启动.bat
```

## 🖱️ 操作速查

| 操作 | 效果 |
|---|---|
| 输入框 + 回车 | 添加今日任务 |
| 单击复选框 | 切换任务完成/未完成 |
| 双击任务文本 | 编辑任务内容 |
| 点击 × 按钮 | 删除任务 |
| 拖动标题栏 | 移动窗口位置 |
| 靠近桌面边缘停留 | 窗口自动缩进 |
| 鼠标移入可见边条 | 窗口重新展开 |
| 右上角 📌 按钮 | 切换窗口置顶 |
| 右上角 × 按钮 | 关闭应用 |

## 📂 数据存储位置

所有任务数据保存在应用目录下：

```
desTop_planApp/
└── appdata/
    └── Local Storage/leveldb/    ← 任务数据（localStorage, Key = desTopPlans）
```
